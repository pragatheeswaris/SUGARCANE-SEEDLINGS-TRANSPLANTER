## AUTOMATIC-SUGARCANE-SEEDLING-TRANSPLANTER---POWER-TILLER

# 🚜 Automatic Sugarcane Seedling Transplanter (Power Tiller Retrofit)
# 📝 Project Overview

The Automatic Sugarcane Seedling Transplanter is an agricultural mechanization system designed to reduce labour dependency and improve planting accuracy in sugarcane cultivation. The system is developed as a retrofit attachment for power tillers, enabling automatic seedling placement, furrow formation, and soil covering in a single pass.
The current prototype demonstrates the tray-based seedling holding and dispensing mechanism, while the final implementation focuses on mechanical synchronization using the power tiller drive, eliminating the need for electrical power in field conditions.

# 🎯 Objectives

-> Reduce labour-intensive manual sugarcane planting

-> Enable automatic and uniform seedling transplantation

-> Minimize dependency on electrical power in agricultural fields

-> Ensure accurate spacing, depth, and alignment of seedlings

-> Design a lightweight retrofit compatible with existing power tillers

-> Improve planting speed and overall farm productivity

# 🛠️ Hardware / Mechanical Components

-> Tray-based seedling holder with multiple cups

-> Dispenser pipe for vertical seedling placement

-> Disc ploughs for furrow closing and soil packing

-> Mild steel (MS) frame structure

-> Power tiller (as drive and mounting platform)

# 💻 Technology & Design Tools

-> Mechanical system design

-> CAD modeling (for frame and mechanism design)

-> Prototype fabrication and welding

-> Field testing and validation

# ⚙️ System Working Principle

-> Seedlings are placed manually into cups arranged on the tray.

-> The power tiller’s forward motion drives the mechanical transmission system.

-> The tray aligns the seedling cup with the dispenser through synchronized movement.

-> The seedling drops vertically into the furrow via the dispenser pipe.

-> Disc ploughs immediately cover and pack soil around the seedling.

-> The process repeats continuously as the tiller moves forward.

# 🌱 Furrow Formation & Soil Packing

-> Furrows are formed ahead of the dispensing point.

-> Seedlings are placed at a uniform depth.

-> Disc ploughs close the furrow instantly after planting.

-> Ensures proper root contact, moisture retention, and seedling stability.

# 🔄 Retrofit Design Concept

-> Designed as a bolt-on attachment for power tillers

-> No major modification required to the tiller

-> Lightweight structure avoids overloading the machine

-> Suitable for flat and mildly sloped fields

-> Compatible with low-gear power tiller operation
